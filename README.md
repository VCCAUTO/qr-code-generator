# QR Code Generator

A modern web application for creating and customizing QR codes.

## Features

- Generate QR codes from text, URLs, and data
- Real-time preview
- Customizable error correction and sizing
- Download in multiple formats (PNG, SVG, JPEG)
- Preset templates for common QR types
- Dark mode support
- Responsive design

## Development

This project is built with React and Vite.

```bash
npm install
npm run dev
```
